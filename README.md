# 炸弹飞机游戏辅助工具

## 项目介绍

这是一个用于「[炸飞机](https://game.hullqin.cn/zfj)」游戏的辅助工具，通过概率分析和并行计算，帮助玩家快速找到游戏中的飞机位置。项目使用Python实现，采用多进程并行计算提高性能，提供了智能的策略来最小化猜测次数。

## 游戏规则

「炸弹飞机」是一种经典的策略游戏，游戏规则如下：

1. 游戏在一个10x10的网格上进行
2. 玩家需要在网格中隐藏3架飞机
3. 每架飞机由1个机头和9个机身组成
4. 玩家通过猜测坐标来寻找对方的飞机
5. 首先找到对方所有3个机头的玩家获胜

## 核心功能

### 1. 解集生成

- 预计算所有合法的飞机布局（约4万种）
- 使用多进程并行计算提高性能
- 缓存机制减少重复计算

### 2. 智能策略

- 基于概率分析选择最可能的机头位置
- 考虑已确认的机头位置，避免重复猜测
- 当多个位置概率相同时，随机选择

### 3. 基准测试

- 评估策略的平均猜测次数
- 统计最大、最小猜测次数和方差
- 帮助优化策略性能

## 安装和使用

### 安装依赖

```bash
# 使用uv安装依赖
uv sync
```

### 运行项目

```bash
# 运行基准测试（默认100次）
uv run main.py
```

### 交互式使用

1. 运行交互式模式后，程序会分析当前局面并推荐最可能的机头位置
2. 输入你选择的坐标和该位置的类型（head/body/blank）
3. 程序会根据反馈更新解集并继续推荐
4. 重复此过程直到找到所有3个机头

## 技术实现

### 多进程并行计算

项目使用Python的`multiprocessing`模块实现并行计算，充分利用多核CPU资源：

- 解集生成时并行计算不同方向组合的布局
- 概率分析时并行计算每个位置的概率

### 缓存机制

- 使用`pickle`序列化保存解集到缓存文件
- 首次运行后，后续启动会从缓存加载，大幅提高启动速度

### 概率分析算法

1. 统计解集中每个位置作为机头的次数
2. 过滤掉已确认的机头位置
3. 选择概率最高的位置作为推荐
